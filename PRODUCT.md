## Platform
web

Mobile web/PWA. Generated iOS/Android shells are retained for deferred native delivery.
## Stack
User-specified lightweight React and TypeScript mobile app, built with Vite. Capacitor shares the interface with generated iPhone and Android projects and provides native location and local-notification adapters. The browser is the current release target; fictional rehearsals run only in the isolated review build.
## Users
Adult Muslims, initially Mamur, using five daily prayers as anchors for reading, exercise, learning, vibecoding, family time and personal growth. Visible progress motivates them; waking for Fajr and stepping away from enjoyable work are barriers. They want meaningful goals/rewards, manageable priorities, practical family planning and optional encouragement without automatic disclosure of private activity. Period mode supports a private pause in prayer tracking.
## Product Purpose
Make the next prayer, next meaningful action and next reward clear. Three saved priorities focus unlimited habits, goal milestones and family tasks. Keep prayer records, habit XP, goal achievement and family completion separate. Support preparation, recovery and explicit control over sharing.
